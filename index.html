FAQ

Before you buy.

Do I need to know JavaScript?

No. The Code nodes are already written. You can change a threshold or a message without touching code; the customization guide shows where.

Which n8n version is this for?

Built for n8n 1.80+ and tested on 2.35.3 self-hosted. The JSON uses current node versions; older instances may need a node upgrade prompt accepted on import.

What accounts do I need?

A Google account with Sheets and Gmail access, and optionally a Telegram bot. The credentials guide covers n8n Cloud, self-hosted OAuth and the exact redirect URL.

Is Google Sheets required?

Yes, Sheets is the database in this pack. That is intentional: you can inspect and edit every row without a database admin. The schema is documented and the XLSX matches it.

Can I use it for client projects?

Yes. The single-business license covers your own business and client projects. You may not resell, redistribute or publish the JSON or docs as a template pack.

Does it work with n8n Cloud?

Yes. The only extra step is Google OAuth: Cloud has a managed Google credential, so you do not create a Google Cloud project. The credentials guide covers both paths.
